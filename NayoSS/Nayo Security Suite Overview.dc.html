Product Overview

Nayo Security Suite

Security migration and management for IFS IEE and IFS Cloud — in one tool.

The Challenge

For most IFS customers, security is the hardest part of moving from an older IFS version to IFS Cloud. Custom permission sets carry over, but their projection grants don't — and remapping them by hand takes weeks of effort.

After go-live, administrators often want a single, consolidated view of security grants and faster ways to handle routine user administration — such as setting up a new user with the same permission sets, companies, sites, and user groups as an existing one.

The Solution

Nayo Security Suite simplifies and streamlines security data management across IFS environments. It migrates security from legacy systems, including IFS IEE, to IFS Cloud. It also lets teams extract, review, modify, and re-import security data within IFS Cloud, and manage users from a single interface.

Key Features

IFS Environment MaintenanceConnect and manage multiple IFS IEE, IFS Aurena, and IFS Cloud environments, with built-in connection testing and SSL verification control.
Permission Set MigrationMap IEE presentation objects to IFS Cloud projections using AI, description, label, and pre-identified mapping. Preview the results, export a mapping summary to Excel, and grant projections to permission sets in one click.
Security Export / ImportExport permission sets from IFS Cloud or IFS Aurena, organized by navigator items, to a spreadsheet that shows None, View, and Edit access at a glance. Update access levels or create new permission sets in the spreadsheet, then import the changes with live progress and logs.
User ManagementGrant and revoke permission sets, companies, sites, and user groups, with a consolidated summary of direct and indirect grants. Duplicate a user with their full access profile, including the person record and sites per user.

Key Benefits

  • Reduce security migration effort from weeks to hours
  • Preserve existing roles, permissions, and security structures through the move to IFS Cloud
  • Get a clear, reviewable view of security grants across IFS Cloud
  • Onboard replacement users in minutes by duplicating an existing user's access
