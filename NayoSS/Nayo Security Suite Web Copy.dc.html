Challenge

Security is the hardest part of the move.

When you upgrade from an older IFS version, custom permission sets come across — but their projection grants need to be rebuilt. Done by hand, that can take weeks.

After go-live, administrators want a single view of who can access what, and a faster way to set up and maintain users.

Features

Everything you need to manage IFS security.

Permission Set Migration

Automatically map IEE presentation objects to IFS Cloud projections using AI, descriptions, labels and pre-identified mappings. Review every match, export a mapping summary to Excel, and grant projections in one click.

Security Export & Import

Export permission sets from IFS Cloud or IFS Aurena into a spreadsheet organized by navigator items, with None, View and Edit access shown at a glance. Update access or create new permission sets in the spreadsheet, then import the changes with live progress and logs.

User Management

Grant and revoke permission sets, companies, sites and user groups from one screen, with a full summary of direct and indirect grants. Duplicate a user's complete access profile — including person record and sites — in a single step.

Environment Maintenance

Connect IFS IEE, IFS Aurena and IFS Cloud environments in minutes, with built-in connection testing and SSL verification control.
